Задача: для первой задачи из X1 написать кроссплатформенный integerset.h (с -fvisibility=hidden)

```jsx
#pragma once

#ifdef _WIN32
    #ifdef BUILD_INTEGERSETDLL
        #define INTEGERSETDLL_API __declspec(dllexport)
    #else
        #define INTEGERSETDLL_API __declspec(dllimport)
    #endif
#else
    #define INTEGERSETDLL_API __attribute__((visibility("default")))
#endif

typedef struct Node {
    int value;
    struct Node *left, *right;
} Node;

typedef struct IntegerSet {
    Node *node;
} IntegerSet;

INTEGERSETDLL_API IntegerSet *CreateSet(const int *arr, int size);

INTEGERSETDLL_API int IsInSet(IntegerSet *set, int value);
```

Задача: написать c.bat и [c.sh](http://c.sh) для этой же задачи

```jsx
gcc integerset.c -std=c99 -O2 -shared -fPIC -fvisibility=hidden -o integerset.so
cl integerset.c /LD /MD /DBUILD_INTEGERSETDLL
```
