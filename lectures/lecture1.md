Общие слова о языке C:
1) Компилируемый язык.
(компиляция)
исходные код —-> машинный код — выполняется процессором нативно
(ассемблер)
Для сравнения: Python интерпретируемый.
Программа-интерпретатор читает текст скрипта, смотрит что там написано, и делает это.

1. Низкоуровневый.
Очень быстрый, крайне небезопасный. По сути “ассемблер высокого уровня”.
Изначально создавался как для кроссплатформенная замена ассемблеру.
До этого ОС писали на ассемблере, причём компьютеров с разными ассемблерами было много.
При программировании на C часто “отстреливаешь себе ногу”, многие критические ошибки даже не приводят к остановке программы!
2. Статически типизированный.
Про любое выражение в тексте программы можно точно сказать, какой тип оно имеет.
Для сравнения: в Python в любую переменную можно записать всё, что угодно, в зависимости от входных данных.

Языки C и C++.
C++ это “C на стероидах” (вся основа из C, плюс добавлена куча возможностей)

Как определить, что есть язык C:
1) Стандарты: начало ~70 год, книга K&R 78, стандарты: ANSI C89, ISO C90, ISO C99, ISO C11
2) Компиляторы: MSVC (Win), GCC (Linux/…), Clang (Linux/…)
!3) Написанные программы: ядра ОС, базы данных, веб-серверы, VCS, языки прогр., обработка медиа, игры прошлого

“Императив” = повеление, указание.
Основные принципы:
1) Последовательное выполнение команд в программе.
2) Память: можно записывать/читать данные в/из переменных.
Пример: программа на русском языке для вычисления среднего балла.

================================ Демо =====================================

```
#include <stdio.h> // включаем заголовочный файл с определениями стандартных функций ввода-вывода
#include <stdlib.h> // включаем заголовочный файл с определениями функций для выделения и освобождения памяти (malloc и free соответственно)

int main() { // функция с именем main (точка входа в программу), которая возвращает целое число. Набор аргументов пустой
    int n; // Объявили переменную целого типа
    int* p; // Объявили переменную, тип которой - указатель на переменную целого типа
    p = &n; // Установвили значение указателя. Теперь p указывает на то место в памяти, где лежит переменная n. Используя p, теперь можно узнать значение n или изменить его

    if (scanf("%d", &n) == 1) // Читаем с консоли целое число (формат %d). Прочитанное значение будет присвоено переменной n, для этого мы в качестве второго аргумента передаём функции scanf указатель на эту переменную
        printf("Hello, world! %d\n", n + 1); // scanf возвращает количество прочитанных значений. Если это количество равно 1, то успешно прочитали число. Теперь выводим отформатированную строку
    else
        printf("Error\n"); // Сообщаем, что прочитать число не удалось - на вход подали что-то, что невозможно интерпретировать как число

    char *s = (char*)malloc(100 * sizeof(s[0])); // Аллоцируем буфер, способный хранить 100 символов

    if (s == NULL) // Проверяем, что буфер удалось аллоцировать
        printf("Memory allocation error");
    else {
        scanf("%s", s); // Читаем строку с консоли в аллоцированный буфер. ВНИМАНИЕ, так делать нельзя! Это небезопасно, поскольку здесь кроется потенциальный срыв буфера. Если нам подадут строку длиннее, чем может вместить буфер, то мы перепишем произвольные значения в памяти
        printf("%s\n", s); // Выводим прочитанную строку на консоль
        free(s); // Освободили буфер
    }

    return 0; // Нулевой код возврата указывает, что программа завершилась корректно
}
```
