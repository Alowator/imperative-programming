# lectureX12

===================== Поток в сети ======================

Если раньше рёбра графа были дорогами, теперь они будут ТРУБАМИ.

Через трубы будем качать “поток” — какой-нибудь материал (воду/нефть).
Поток, текущей по трубе, можно измерить: например 5 кубометров в секунду (сколько протекает через сечение в единицу времени).
Трубы не резиновые: у каждой трубы указана “пропускная способность” — какой максимальной величины поток через неё разрешено пропускать.

Имея пропускные способности, уже можно гонять поток по трубам. Не хватает только цели.
Выделим две вершины: исток s и сток t. Будем качать нефть из s в t.
Задача: с какой максимальной скоростью можно поставлять нефть из s в t на заданной сети труб?

В теории “сеть” — это граф с выделенными истоком s и стоком t, а также с проставленными у рёбер пропускными способностями.
Вышеописанная задача — это задача поиска максимального потока в сети N.

Заметим, что трубы могут быть разные:
1) Двусторонние: пропускная способность c в обе стороны.
2) Односторонние: пропускная способность c в одну сторону и 0 в обратную.

================= Хранение сети в памяти ================

1. Матрица смежности.
c(u, v) — пропускная способность трубы из u в v (0 если трубы нет)
f(u, v) — величина потока по трубе из u в v
Можно хранить эти величины в матрицах.

Такое представление плохо работает на разреженных графах.
Зато оно удобно для теории: далее оно будет использоваться в лекции.
Кроме того, большая часть задач из набора решается таким образом.

1. Списки инцидентности.
Можно хранить для каждой вершины список рёбер, которые из неё выходят.

ВАЖНО: в задачах на поток ВСЕ рёбра “двойные”, у каждого ребра есть обратное!
Если по ребру uv течёт поток f, то по обратному ребру всегда течёт поток -f.
В алгоритмах иногда нужно находить для ребра обратное.

Простой способ хранить списки инцидентности:
struct Edge {
int from, to; //откуда/куда идёт это ребро (номера вершин)
int cap; //пропускная способность этого ребра в этом направлении
int flow; //величина потока по этому ребру в этом направлении
};
Edge edges[…]; //классический список рёбер
IntList inc[…]; //списки инцидентности
Здесь inc[u] — это список НОМЕРОВ (в edges) всех рёбер, которые выходят из u.

При построении графа, когда очередное ребро добавляется в граф, СРАЗУ после этого надо добавить обратное ребро.
Тогда в массиве рёбра edges[2k] и edges[2k+1] будут обратными друг другу (для всех k).
Если так сделать, то можно легко вычислить по номеру ребра z номер обратного ребра nz.
Короткий способ:
nz = z^1;
Обычно для добавления трубы пишется отдельная функция, чтобы потом можно было легко строить сеть.

==================== Потоки и разрезы ===================

> Чтобы f было потоком, должны выполняться условия:
1) f(u,v) = -f(u,v) (кососимметричность)
Существенно упрощающает работу с потоками.
2) sum_v f(u,v) = 0 (закон сохранения потока — только для u != s, t)
Иными словами: сколько в u втекает, столько и вытекает (нефть не теряется).
В силу кососимметричности втекающие потоки в сумме учитываются со знаком минус, а вытекающие — со знаком плюс.
3) f(u,v) <= c(u,v) (ограничение на пропускную способность)
> 

> Разрезом называется разбиение вершин графа на две части, так что исток оказывается в левой части, а сток — в правой:
union(A, B) = V
intersect(A, B) = {}
s in A
t in B
Обозначается как: A|B
> 

Рёбра разреза — это все рёбра, у которых начало находится в A, а конец — в B (т.е. {uv in E | u in A, v in B})
Для разреза можно определить: поток через него, и его пропускную способность.
Для этого надо просто просуммировать соотв. величину по всем рёбрам разреза:
f(A|B) = sum_{u in A} sum_{v in B} f(u, v)
c(A|B) = sum_{u in A} sum_{v in B} c(u, v)

Можно заметить, что:
1) f(A|B) <= c(A|B) — очевидно
2) Число f(A|B) одинаковое для любого разреза.
Это очевидно из интуитивных соображений: если потёрь нет, через границу A|B должно течь ровно столько потока, сколько мы высылаем из истока.

> Величиной потока называется f(A|B) для любого разреза — т.е. с какой скоростью мы переправляем нефть из s в t.
В частности, его можно посчитать как суммарный вытекающий из s поток, или как суммарный втекающий в t поток:
|f| = f(A|B) для { A = {s}, B = V{s}
{ A = V{t}, B = {t}
> 

Классические задачи на потоки:
1) Найти максимальный поток, то есть поток f, для которого |f| = max
Фактически показывает, как нужно качать нефть, чтобы получилась максимальная скорость.
2) Найти минимальный разрез, то есть разрез A|B, для которого c(A|B) = min
Показывает, где в сети “узкое место”, то есть в какой разрез следует добавлять трубы, чтобы увеличить макс. поток.
Также разрез возникает в задачах в стиле: удалить набор рёбер минимального суммарно веса, чтобы отделить вершины s и t друг от друга.

================== Метод Форда-Фалкерсона =================

> Остаточная сеть Nf для потока f в сети N — это исходная сеть N с некоторыми изменениями:
1) У каждого ребра “остаточная” пропускная способность равна: cf(u,v) = c(u,v) - f(u,v)
(обычно считается, что ребро “есть” в остаточной сети только когда cf(u,v) > 0 для него)
2) Поток f в остаточной сети Nf стирается.
> 

ВАЖНО: даже если трубы были односторонними, то в остаточной сети появляются обратные рёбра!
Обратные рёбра необходимы алгоритмам поиска макс. потока, чтобы правильно работать.
Без этого они не могут “передумать” о своих решениях, т.е. развернуть часть потока по какому-то ребру.

Остаточная сеть показывает, сколько можно пропихнуть дополнительно потока по каждой трубе в сети.
В частности, если в остаточной сети Nf построить какой-то поток df, то его можно добавить к текущему потоку f в исходной сети N.
Величина потока |f| при этом увеличится в точности на величину потока |df|.

Можно брать поток g простого вида, например поток вдоль пути P.
Любой путь из s в t в остаточной сети называется “дополняющим путём”.
По нему можно пустить поток, величина которого определяется минимальной остаточной пропускной способностью вдоль пути.
Этот поток можно добавить к текущему потоку в исходной сети N, тем самым увеличив её.

Метод Форда-Фалкерсона поиска максимального потока:
f = 0
while в остаточной сети Nf есть дополн. путь P:
добавляем поток вдоль P
При добавлении потока имеет смысл определить минимальную остаточную пропускную способность вдоль пути.
Именно столько потока мы может добавить вдоль пути без дополнительных ухищрений.

Замечание: в алгоритмах остаточная сеть Nf явно не строится: её рёбра определяются “на лету” вычитанием c(u,v)-f(u,v).
При проталкивании (добавлении) потока вдоль пути нужно также обновить поток по обратным рёбрам: здесь нужно уметь находить обратное ребро.

Вопрос: а верно ли, что когда дополняющие пути закончатся, получится именно максимальный поток?
Может быть мы упрёмся в потолок где-то ниже?

> Теорема Форда-Фалкерсона.
Пусть f — поток в сети N. Тогда эквивалентны условия:
1) |f| = max (поток максимальный)
2) В остаточной сети Nf нет дополняющего пути из s в t.
3) Существует разрез A|B, у которого пропускная способность равна |f| (нетрудно заметить, что такой разрез минимальный)
> 

В доказательстве теоремы видно, как искать минимальный разрез:
cтроим максимальный поток f
смотрим на остаточную сеть Nf
запускаем в Nf обход из s, все достижимые вершины кладём в A
в B кладём все остальные вершины
Тогда A|B — минимальный разрез.

Конкретные алгоритмы на основе метода Форда-Фалкерсона.

1. На каждом шаге ищем ЛЮБОЙ дополняющий путь P, например используя DFS.
Можно заметить, что если все пропускные способности целые, то и поток в алгоритме всегда целый.
Значит на каждом шаге величина потока увеличивается хотя бы на 1 — независимо от выбора пути.
Тогда всего путей будет не больше |f|.

Учитывая, что DFS работает за O(E + V), получаем (игнорируя O(V)):
Время работы: O(|f| E)
Это хорошая оценка, если максимальный поток целый и МАЛЕНЬКИЙ.

Интересный факт: если пропускные способности иррациональные,
то на специально подобранной сети и при специальном выборе дополняющих путей метод Форда-Фалкерсона может работать ВЕЧНО.

1. На каждом шаге ищем минимальный по кол-ву рёбер дополняющий путь, используя BFS.
Это называется “алгоритм Эдмонса-Карпа”.
Известно, что в этом случае количество дополняющих путей не превышает O(V E) (это крайне пессимистичная оценка: на большинстве примеров нужно гораздо меньше путей)
Получается общая оценка времени: O(V E^2).

Полный алгоритм поиска макс. потока:

f = 0
while true:

```
// part 1: BFS
mark[*] = false
mark[s] = true
Q.push(s)
while Q is not empty:
  u = Q.pop()
  for uv in E:
    if c(uv) - f(uv) > 0:   // проверяем cf(uv) -- остаточную проп. спос-сть
      if not mark[v]:
        mark[v] = true
        Q.push(v)
        F[v] = u
if !mark[t]:
  break                     // нет дополняющего пути

// part 2: how much?
CP = +inf
x = t
while x != s:               // восстанавливаем путь P первый раз
  y = F[x]
  CP = min(CP, c(yx) - f(yx))
  x = y

// part 3: push flow
x = t
while x != s:               // восстанавливаем путь P второй раз
  y = F[x]
  f[yx] += CP
  f[xy] -= CP               // не забываем поменять поток по обратному ребру!
  x = y
```

======================== Приложения ======================

1. Поиск максимального паросочетания в двудольном графе.

Задача: есть парни и девушки.
Какие-то парни знакомы с какими-то девушками.
Нужно переженить как можно больше пар, при условии:
1) женить можно только знакомых
2) многожёнство/многомужничество запрещено

В терминах теории графов: есть двудольный граф (левая доля — мальчики, правая — девочки).
Рёбра — это знакомства (могут быть только между долями).
Паросочетание — это набор рёбер без общих концевых вершин.
Нужно найти максимальное паросочетание (по количеству рёбер).

Алгоритм решения:
Добавляем новые вершины: исток s и сток t.
Из истока s в каждую вершину u левой доли добавляем ребро.
Из любой вершины v правой доли добавляем ребро в сток t.
Приписываем всем рёбрам пропускную спосбность 1.
Находим максимальный поток из s в t.
Искомое паросочетание — это те рёбра между долями, по которым течёт поток.

картинка: —u1 …

/ … v1—

/*—u2 …  
s* … v2—-t
 —u3 … /
  … v3—
—u4 …

Поскольку проп. способности целые и единичные, в макс. потоке все величины будут 0 или 1.
Если посмотреть на рёбро uv между долями, по которому течёт поток, то:
в начало u втекает единица потока (из s по ребру su)
из конца v вытекает единица потока (в t по ребру vt)
Это так в силу закона сохранения потока и того, что больше потоку неоткуда браться/неоткуда течь.
Заметим, что и этих рёбер uv не может быть общих концевых вершин, т.к. иначе или из s поток был бы больше единицы, либо в t тёк бы поток больше 1.
По сути, рёбра su обеспечивают несовпадение левых вершин и рёбра, а vt — правых.

Можно показать, что верно обратное: для любого паросочетания строится соответствующий поток в этой сети.

1. Рёберная теорема Менгера.

Есть граф c выделенными вершинами s и t.
Теорема Менгера гласит, что следующие числа совпадают:
максимальное количество путей из s в t без общих рёбер
минимальное количество рёбер, при удалении которых нельзя добраться из s в t

Если рассматривать граф как сеть с единичными пропускными способностями, то:
любой набор путей из s в t без общих рёбер — это поток в сети, а по любому потоку можно построить непересекающиеся пути
рёбра любого A|B разреза дают набор рёбер, удаление которых ведёт к несвязности s и t
В таком случае теорема Менгера следует из теорема Форда-Фалкерсона для этой сети.

Найти рёберно-непересекающиеся пути (макс. кол-во) можно так:
ищем максимальный поток f в сети
while |f| > 0:
находим любой путь P из s в t, вдоль которого течёт поток
вычитаем из потока f единичный поток вдоль P (стираем поток вдоль P)

Для поиска пути вдоль потока достаточно обычного цикла, никакого DFS/BFS не требуется.

В конце останется поток |f| = 0.
В нём всё ещё может течь какой-то поток по кругу.

Время работы: O(E^2) —- т.к. |f| <= |E|

1. Вершинная теорема Менгера.

Есть граф c выделенными вершинами s и t.
Теорема Менгера гласит, что следующие числа совпадают:
максимальное количество путей из s в t без общих промежуточных вершин
минимальное количество вершин, при удалении которых нельзя добраться из s в t

Чтобы найти вершинно-непересекающиеся пути, нужно ограничить количество путей, которые идут через каждую вершину.
В сети можно ограничивать только объём потока через рёбра.
Значит нужно воткнуть в каждую вершину по ребру, и как-то заставить поток течь по этим рёбрам при прохождении вершины.

Решение: строим удвоенный граф, у каждой вершины u есть “верхняя” вершина u1 и “нижняя” вершина u2.
Строим рёбра:
1) Для каждой вершины u ставим ребро из u1 в u2 (т.е. вниз) пропускной способности 1.
2) Для каждого ребра uv исходного графа ставим ребро из u2 в v1 (если граф неориентированный, надо ещё добавить ребро из v2 в u1).
(картинка)

Получается, что поток по-прежнему распадается на пути, но при прохождении каждой вершины путь вынужден “протекать вниз”.
Это делается через ребро единичной пропускной способности, что обеспечивает отсутствие пересечений по вершине.

Алгоритм поиска вершинно-непересекающихся путей:
строим удвоенный граф
находим максимальный поток f из s2 в t1
высекаем из потока f пути так же, как в предыдущем алгоритме

Время работы: O(V E) —- т.е. |F| <= |V|

Дополнительный материал (знать НЕ нужно).

> Теорема Форда-Фалкерсона.
Пусть f — поток в сети N. Тогда эквивалентны условия:
1) |f| = max (поток максимальный)
2) В остаточной сети Nf нет дополняющего пути из s в t.
3) Существует разрез A|B, у которого пропускная способность равна |f| (нетрудно заметить, что такой разрез минимальный)
> 

Доказательство:

1->2) От противного.
Если есть дополн. путь P в остаточной сети Nf, то по нему можно протолкнуть дополнительный поток.
Этот поток будет иметь величину min_{uv in P} cf(uv) > 0, и на это число увеличится величина потока.
Тогда исходный поток f не максимален, т.к. мы можем его увеличить — противоречие.

2->3) Запустим в остаточной сети Nf обход из истока s.
Обозначим достижимое множество через A.
Если t in A, тогда существует дополн. путь из s в t, чего нет по условию.
Тогда A|B — это разрез (B = V— все недостижимые вершины)
Заметим, что все рёбра этого разреза “насыщенные”, т.к. они отсутствуют в остаточной сети Nf.
Значит для каждого ребра c(uv) = f(uv), а следовательно по всему разрезу c(A|B) = f(A|B) = |f|.

3->1) Пусть для разреза c(A|B) = |f|.
Величину потока можно записать как f(A|B), то есть c(A|B) = f(A|B).
Как известно, всегда верно f(A|B) <= c(A|B), а значит величина потока никак не может стать больше — она уже упёрлась в пропускную способность этого разреза.
