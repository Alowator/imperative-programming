# lecture2

Можно инициализировать переменную в момент объявления:
int x = 5;
Объявление нескольких переменных в одной строке:
int x = 5, y, k = 0;

Операторы изменения:
a += b; //эквивалентно: a = a + b
a -= b;
a *= b;
…
Операторы инкремента/декремента:
i++; // эквивалентно: i += 1 ПОСТинкремент
++i; // эквивалентно: i += 1 ПРЕинкремент
i–; // эквивалентно: i -= 1 ПОСТдекремент
–i; // эквивалентно: i -= 1 ПРЕинкремент
Разница между постинкрементом и преинкрементом:
printf(“%d”, i++); //выведется старое значение, а переменная станет больше на 1
printf(“%d”, ++i); //переменная увеличится, и выведется новое значение
Подобное использование будет важно при работе с массивами:
arr[k++] = x;
x = arr[–k];

Блоки { … } — могут быть вложенными, можно заводить просто так.
Область видимости и жизни переменной: ниже объявления до конца текущего блока.

Цикл for:
for (инициализация; условие; переход на след. итерацию) { … }
Любой цикл for можно преобразовать к эквивалентному циклу while:
инициализация
while (условие) {
…
переход на след. итерацию
}
Канонический вариант цикла в C (перебирает целые от 0 до n-1):
for (int i = 0; i < n; i++) { … }

Если внутри for/while/if одна команда (утверждение), то можно не окружать её фигурными скобками:
int sumSquares = 0;
for (int i = 0; i < n; i++)
sumSquares += i * i;

Пример: считаем сумму a*b для точек (a, b) внутри круга радиуса N (a, b — неотр)
В for можно писать нетривиальные условия, вроде:
for (int x = 0; x <= rad; x++)
for (int y = 0; x*x + y*y <= rad*rad; y++)
sum += x * y;
Заметим, что можно писать вложенные циклы и if-ы.

Переход на след. итерацию цикла:
continue;
Выход из цикла:
break;

Типы данных:
int — целое число
double — вещественное число
char — символ

Объявление переменной какого-то типа:
тип_переменной имя_переменной;

Константы типов int/double/char в коде:
int x = 773;
double y = -13.513;
char z = ’*‘; //’’ — тоже один символ

Чтение и запись переменной разного типа:
scanf(“%d” , &x); printf(“%d” , x);
scanf(“%lf”, &y); printf(“%lf”, y);
scanf(“%c”, &z); printf(“%c” , z);

ВАЖНО: при чтении scanf(“%c”, …) читается следующий символ, даже если это пробел или перевод строки.
Так можно делать посимвольный ввод.
При чтении переменной другого типа автоматически пропускаются все пробельные символы (пробелы и переводы строк).
Чтобы выполнить этот пропуск явно, можно сделать:
scanf(” “);

Конструкция if/elseif/else в общем виде:
if (условие1) { … }
else if (условие2) { … }
else if (условие3) { … }
else { … }

Условия вычисляются по очереди сверху вниз.
Как только условие оказывается верным, соответствующее тело выполняется, после чего выполнение выходит в самый конец конструкции.
Всегда выполняется ровно одно тело, условия вычисляются лишь до тех пор, пока одно из них не окажется верным.

Пример: определить взаимное положение двух отрезков

Булевого типа в языке C нет.
Условие внутри if считается:
ложью: если его значение равно нулю
истиной: если значение НЕ равно нулю

Сравнения и логические операторы всегда возвращают целое значение: 0 или 1.

Операторы логического И, логического ИЛИ и отрицания:
x && y — истинно, когда истинны оба значения x и y
x || y — истинно, когда истинно хотя бы одно из значений x и y
!x — истинно, когда x ложно

Приоритеты операций:
арифметика > сравнения > логические операторы
*,/ раньше +,- // как в математике
! раньше && раньше || // как в математике

Порядок вычисления выражений одного приоритета: слева направо // как в математике
При необходимости можно поменять порядок, заключив подвыражение в скобки.

Сокращённое вычисление логических выражений:
При вычислении логического И или ИЛИ,
если результат можно определить по значению первого аргумента,
то второй аргумент не вычисляется!
Очень важно будет при работе с массивами и указателями!
