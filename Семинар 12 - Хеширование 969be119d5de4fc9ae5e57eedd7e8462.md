**Вопрос**: какие есть способы реализовать хеш-таблицу?

1. На списках *рисуем*
2. Используя открытую адресацию *рисуем* - вариант не самый простой, так как просто так удалять элементы нельзя, если h(k) = i, а в действительности он лежит в ячейке j, то весь диапазон от i до j должен быть занят, удалять элементы оттуда просто так нельзя.

**~~Задача**: реализовать хеш-таблицу~~

```jsx
uint32_t jenkins(const uint8_t* key, size_t len) {
    uint32_t hash = 0;    for (size_t i = 0; i < len; i++) {
      hash += key[i];      hash += hash << 10;      hash ^= hash >> 6;    }
    hash += hash << 3;    hash ^= hash >> 11;    hash += hash << 15;    return hash;}
```

**Вопрос**: можем ли мы быстро найти все имена владельцев номеров в диапазоне?
